# Excel Sudoku Solver

## Description
This is a Sudoku solver implemented entirely in Excel using formulas and VBA macros.  
It takes an incomplete Sudoku puzzle and automatically fills in the solution.

## Technologies
- Microsoft Excel
- Formulas and VBA for logic

## How to Run
1. Open `sudoku_solver.xlsx` in Excel.
2. Input the puzzle numbers in the designated cells.
3. Click solve.
